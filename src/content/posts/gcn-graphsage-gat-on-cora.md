## 继续比较三种 GNN

前面已经在 Cora 上训练过两层 GCN，也验证了图结构确实能给节点分类带来帮助。这一轮
没有换任务，而是把 GCN 分别替换成 GraphSAGE 和 GAT，看看三种模型在邻居聚合上到底
有什么区别。

它们的整体结构其实差不多：

```text
节点特征 → 图卷积 → 激活函数 → Dropout → 图卷积 → 类别分数
```

真正不同的是中间那一步：一个节点应该怎样接收邻居的信息。

## GCN：由图结构确定权重

GCN 使用加入自环并归一化后的图结构传播信息。邻居权重主要由节点的度数决定，不是为
每一条边单独学习出来的。

可以把它粗略理解为：

```text
先按节点度数缩放邻居消息，再把它们加到一起
```

GCN 简单、稳定，也是后面比较其他模型时很合适的基线。

## GraphSAGE：聚合邻居，再结合自己

GraphSAGE 会先聚合邻居表示，再和节点自身的表示结合。常见聚合器包括 `mean`、`max`
等。

```python
from torch_geometric.nn import SAGEConv

conv = SAGEConv(
    in_channels=input_dim,
    out_channels=hidden_dim,
    aggr="mean",
)
```

GraphSAGE 的另一个重要特点是可以做邻居采样。假设一个节点有 10 万个邻居，完整读取
并聚合所有邻居会带来很大的内存和计算开销。训练时只采样固定数量的邻居，可以把局部
计算图的大小控制住。

采样提高了效率，但也不是没有代价：它会引入随机性，而且可能漏掉有用的邻居。

## GAT：学习哪些邻居更重要

GAT 使用注意力机制，为不同邻居学习不同的消息权重。

```python
from torch_geometric.nn import GATConv

conv = GATConv(
    in_channels=input_dim,
    out_channels=8,
    heads=4,
    concat=True,
)
```

这里每个注意力头输出 8 维，一共有 4 个头。当 `concat=True` 时，各个头的结果会拼接
起来，所以总输出维度是：

```text
8 × 4 = 32
```

如果把头数改成 8，总输出就会变成 64 维。多头注意力并不是“头越多越好”，因为它还会
改变隐藏维度、参数量和计算成本。

## 三个两层模型

为了公平比较，三个模型都使用两层图卷积，并保持相同的数据划分、训练轮数、优化器和
最佳模型选择方法。

它们最终都需要输出：

```text
[2708, 7]
```

也就是 Cora 的 2708 个节点，每个节点对应 7 个类别分数。这次设置下的参数量为：

| 模型 | 参数量 |
|---|---:|
| GCN | 46,119 |
| GraphSAGE | 92,199 |
| GAT | 46,197 |

GraphSAGE 的参数更多，是因为它需要分别处理自身信息和聚合后的邻居信息。但参数更多
并不等于效果一定更好。

## 单次训练结果

固定随机种子为 42，每个模型训练 101 轮，并根据验证集损失恢复最佳权重：

| 模型 | 训练准确率 | 验证准确率 | 测试准确率 |
|---|---:|---:|---:|
| GCN | 0.986 | 0.786 | 0.810 |
| GraphSAGE | 1.000 | 0.768 | 0.805 |
| GAT | 0.986 | 0.790 | 0.806 |

这一次运行中，GAT 的验证集准确率最高，而 GCN 的测试准确率最高。模型选择应该依据
验证集，因此不能看到 GCN 的测试结果更高，就回头宣布应该选择 GCN。

测试集的职责是最终评价。如果用测试结果不断选择模型，测试集信息就参与了调参，最后
得到的成绩会过于乐观。

## mean 和 max 聚合器

我还比较了 GraphSAGE 的两种聚合方式：

| 聚合器 | 验证准确率 | 测试准确率 |
|---|---:|---:|
| mean | 0.768 | 0.805 |
| max | 0.776 | 0.785 |

根据验证集，这次应该选择 `max`；但 `mean` 的测试准确率反而更高。这正好再次说明：
不能根据测试集结果回头修改选择。

另一个容易踩坑的地方是，不能在 `SAGEConv` 创建以后只修改：

```python
conv.aggr = "max"
```

因为内部聚合模块已经初始化完成。更稳妥的方式是在创建层时直接传入 `aggr`：

```python
SAGEConv(input_dim, hidden_dim, aggr="max")
```

## 多个随机种子

一次训练会受到权重初始化和 Dropout 等随机因素影响，因此又使用随机种子
`[0, 1, 2]` 重复训练：

| 模型 | 三次测试准确率 | 均值 | 标准差 |
|---|---|---:|---:|
| GCN | 0.818、0.815、0.821 | 0.818 | 0.003 |
| GraphSAGE | 0.791、0.800、0.803 | 0.798 | 0.006 |
| GAT | 0.817、0.828、0.826 | 0.824 | 0.006 |

在这组实验设置下，GAT 的测试均值最高。但这里只运行了三个随机种子，结果更适合用来
练习规范的比较流程，而不是证明 GAT 在所有任务上都优于另外两个模型。

## 注意力不等于因果解释

PyG 可以返回 GAT 在每条边上的注意力权重：

```python
output, (edge_index, attention) = conv(
    x,
    edge_index,
    return_attention_weights=True,
)
```

这些权重说明模型在这次前向传播中怎样分配邻居消息，但不能直接证明某个邻居是预测结果
产生的真实原因。

“模型更关注谁”和“谁在因果上导致了结果”是两件事。注意力可以作为分析模型行为的一条
线索，但不能自动当成可靠的因果解释。

## 一层还是两层

和 GCN 一样，GraphSAGE 与 GAT 每经过一层消息传递，就把感受范围向外扩展一跳：

```text
一层：节点自身 + 一跳邻居
两层：节点自身 + 一跳邻居 + 最多两跳邻居
```

层数增加并不意味着可以一直获得更好的信息。层数太深时，还可能遇到过平滑、训练困难
和计算范围快速扩张等问题。

## 这次记住的几点

- GCN、GraphSAGE 和 GAT 最核心的区别是邻居聚合方式；
- GraphSAGE 可以通过邻居采样处理更大的图；
- GAT 使用多头注意力时，要仔细计算拼接后的输出维度；
- 参数更多、结构更复杂，不代表结果一定更好；
- 模型选择看验证集，测试集只用于最后评价；
- 一次运行不够，正式比较应该使用多个随机种子；
- 注意力权重可以帮助观察模型，但不自动等于因果解释。
